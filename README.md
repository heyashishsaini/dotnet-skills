# .NET Skills

Welcome to the **dotnet-skills** repository. This project serves as a structured, centralized knowledge base and reference guide for mastering the .NET ecosystem, ranging from core desktop development to advanced architectural patterns and interview preparation.

---

## 📂 Repository Structure

The repository is organized into targeted directories, each focusing on a specific pillar of .NET expertise:

* **`dotnet-main/`** Core .NET fundamentals, foundational runtime concepts, C# language features, and modern framework updates.
    
* **`dotnet-architect/`** Advanced design patterns, system architecture, microservices, cloud-native practices, and enterprise-level application design principles.
    
* **`dotnet-wpf/`** Desktop application development using Windows Presentation Foundation (WPF). Covers XAML, MVVM pattern implementation, data binding, and desktop UI/UX.
    
* **`dotnet-interview-notes/`** Curated technical questions, coding challenges, conceptual deep-dives, and preparation material for .NET developer interviews.
